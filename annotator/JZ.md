# JZ：减字谱标注语言

每一页是一个纯文本文件 `data/pages/<页名>.jz`，一行一个减字：

```
<语义层>   @x,y,宽,高   [| 微调层]   [✓]   [! 备注]
```

- **语义层**：只写这个字在琴谱里的意思，例如 `名十勾四`。
- **@框**：这个字在扫描图上的位置（以扫描图像素为单位），由编辑器拖动生成。
- **微调层**（可省略）：只调整位置、大小和所用的变体，**不改变含义**。删掉微调层，字的意思不变，只是回到默认排版。
- `✓` 表示已经人工校对；`! …` 是备注（编辑器里显示为红点）。
- `#` 开头的行是注释。文件头的 `scan` 给出扫描图和尺寸，`scale` 是符号库 pt 到扫描像素的换算比例。

## 语义层

一个减字由下列部分按顺序组成，每一部分都可以省略：

| 部分 | 写法 | 字形位置 |
|---|---|---|
| 散音 | `散` | 上部 |
| 左手指 + 徽位 (+ 分) | `大` `食` `中` `名` `跪`，后接 `一`…`十三`；分位写作 `九八分` | 上部，指在左、徽在右 |
| 右手指法 + 弦 | `勾 挑 抹 打 剔 摘 历 托 轮 蠲 扶 …` 后接弦数 | 下部 |

例：`名十勾四`、`散挑七`、`大九八分剔五`、`十挑四`（省略左手指，沿用前一指）、`食扶`（只写指、不写徽）。

其他写法：

| 写法 | 含义 |
|---|---|
| `四` | 单独的弦数 |
| `撞` `猱` `注` `吟` … | 单独的术语，使用符号库同名组件 |
| `三作` `引上十` | 小字注、术语序列：竖排堆叠，数字自动选用小号变体 |
| `'樵'` `'引上十'` | 引号内是普通字，直接用字体字形，不做任何减字解析 |
| `。` | 句读圈 |
| `○正` `○巳` | 圈字 |
| `{结构式}` | 逃生口：语义无法表达时直接写字形结构，见下文 |

## 自动排版：风格排版

标准减字（散 / 指徽分 / 法弦 / 单独的数与术语）用**风格排版**，规则全部从已完成的《获麟》《酒狂》中学来（`data/style.json`）：

- **部件按设计原大摆放，只允许小幅缩放**（0.8–1.25 倍）。要更小或更大的数字时，不缩放，而是换一个本来就是那个尺寸的变体。
- **变体由「角色 + 上下文」决定**：例如有上半部的打用「矮打」，其中的三用「小32」；徽位用「上N」。单独的数字则按原谱字框大小挑最接近的变体。
- **部件之间是咬合、半包的**，相对位置取自原作中离散度最小的基准：
  - 弦：中心落在指法外框内的固定比例位置（按指法组件分别学习）；
  - 指：中心与指法中心水平对齐（带偏移），竖向以下半部顶边为基准——指会插进「勹」里；
  - 徽：右边对齐下半部右边，顶边对齐指的顶边；分：在徽之下。
- 整个字组好后，统一乘以页面比例 `scale`（扫描像素 / pt），居中放进字框。

左手指（名1/名2/名3、大1/大2/大3）用哪一个，原作中由原谱刻本的笔势决定，语义推断不出来，请在微调层用 `指=大3` 指定。

引号文字、小字注和 `{结构式}` 仍用格子排版：各部件按比例分格。

### 评测与回流

- `tools/extract_layout.py`：从成品 PDF 中提取每个符号实例（组件名、位置、缩放）；
- `tools/gt_chars.py`：按减字结构把实例分组，并反推语义，得到标准答案集 `data/gt-chars.json`；
- `tools/learn_style.py`：学习风格表；加 `--pages data/pages` 时，已校对（✓）字的微调偏移按「角色|指法」取中位数并入默认位置（同类至少 3 例才生效）；
- `tools/eval_predict.js` + `tools/eval_compare.py`：用 JZ 重新排版标准答案中的字，分元素层（变体、部件偏差）与像素层（IoU）比对。

留出评测（只用《获麟》学习，在《酒狂》的 67 个完整减字上测）：

| | 弦变体正确 | 弦偏差 | 指偏差 | 整字对齐后像素 IoU（中位） |
|---|---|---|---|---|
| 旧格子排版 | 22/66 | 4.7pt | 5.0pt | 0.47 |
| 风格排版 | 43/66 | 1.3pt | 2.6pt | 0.61 |
| 风格排版，变体人工指定 | 66/66 | 1.3pt | 2.9pt | 0.64 |

## 微调层

用空格分隔，按**角色**引用部件：

| 角色 | 指哪个部件 |
|---|---|
| `散` `指` `徽` `分` `法` `弦` | 语义层里对应的部分（`徽十` 指「十一」「十二」里的「十」） |
| `数` `字` `圈` | 单独的弦数 / 术语 / 圈 |
| `文1` `文2` … | 引号文字或小字注里的第 N 个字 |

| 写法 | 作用 |
|---|---|
| `弦~1.5,-2` | 部件偏移 (dx, dy)，扫描图像素 |
| `徽*0.9` | 部件缩放 |
| `弦=小32` | 指定所用变体（组件名） |
| `弦='四'` | 指定用字体字形 |
| `/40` | 上下分割：上部占 40%（仅格子排版） |
| `\|60` | 上部的左右分割：左手指占 60%（仅格子排版） |

例：`名十打四 @388,28,44,68 | 指=名2 弦~0,1`

编辑器里拖动部件、缩放部件、按 `[` `]` 切换变体，都只会改写微调层。

## 结构式（逃生口）

`{…}` 内直接写字形结构，原子是组件名、引号字形或 `○`：

| 运算 | 含义 |
|---|---|
| `A / B` | A 在上、B 在下；`A /40 B` 指定上部占 40% |
| `A \| B` | A 在左、B 在右 |
| `A[B]` | B 放进 A 的内框 |
| `A + B` | 叠放在同一格 |
| `( )` | 分组 |

原子后可直接跟 `~dx,dy`、`*倍数`。结构式里的部件按出现顺序命名为 `#1`、`#2`…，结构式自带微调，不再使用 `|` 微调层。

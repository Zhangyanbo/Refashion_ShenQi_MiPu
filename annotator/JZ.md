# JZ：减字谱标注语言

每一页是一个纯文本文件 `data/pages/<页名>.jz`，一行一个减字：

```
<语义层>   @x,y,宽,高   [| 微调层]   [✓]   [! 备注]
```

- **语义层**：只写这个字在琴谱里的意思，例如 `名十勾四`。
- **@框**：这个字在扫描图上的位置（以扫描图像素为单位），由编辑器拖动生成。
- **微调层**（可省略）：只调整位置、大小和所用的变体，**不改变含义**。删掉微调层，字的意思不变，只是回到默认排版。
- `✓` 表示已经人工校对；`! …` 是备注（编辑器里显示为红点）。
- `#` 开头的行是注释。文件头的 `scan` 给出扫描图和尺寸，`scale` 是符号库 pt 到扫描像素的换算比例。

## 语义层

一个减字由下列部分按顺序组成，每一部分都可以省略：

| 部分 | 写法 | 字形位置 |
|---|---|---|
| 散音 | `散` | 上部 |
| 左手指 + 徽位 (+ 分) | `大` `食` `中` `名` `跪`，后接 `一`…`十三`；分位写作 `九八分` | 上部，指在左、徽在右 |
| 右手指法 + 弦 | `勾 挑 抹 打 剔 摘 历 托 轮 蠲 扶 …` 后接弦数 | 下部 |

例：`名十勾四`、`散挑七`、`大九八分剔五`、`十挑四`（省略左手指，沿用前一指）、`食扶`（只写指、不写徽）。

其他写法：

| 写法 | 含义 |
|---|---|
| `四` | 单独的弦数 |
| `撞` `猱` `注` `吟` … | 单独的术语，使用符号库同名组件 |
| `三作` `引上十` | 小字注、术语序列：竖排堆叠，数字自动选用小号变体 |
| `'樵'` `'引上十'` | 引号内是普通字，直接用字体字形，不做任何减字解析 |
| `。` | 句读圈 |
| `○正` `○巳` | 圈字 |
| `{结构式}` | 逃生口：语义无法表达时直接写字形结构，见下文 |

## 自动排版规则

- 上部与下部按各自的设计高度分配；上部之内，左手指与徽位按设计宽度分配。
- 勾、打、剔、摘、历、托：弦数放进指法组件的内框（slot，见 `jz.js` 的 `SLOTS`）。抹、轮、蠲：弦数在下。挑：弦数在上，坐进「乚」的凹口。
- **变体自动挑选**：数字（`四` 可能落到 `四`、`小4`、`上4` 或字体字形）和指法（`勾` 可能落到 `标准勾`、`矮勾`、`扁勾`）会按它所分到的格子大小，挑选设计尺寸最接近的那一个，再等比缩放放入格子。这就是原来那张「不同尺度用不同数字」表格的自动化。「侧」字头的变体不参与自动挑选，只能手动指定。

## 微调层

用空格分隔，按**角色**引用部件：

| 角色 | 指哪个部件 |
|---|---|
| `散` `指` `徽` `分` `法` `弦` | 语义层里对应的部分（`徽十` 指「十一」「十二」里的「十」） |
| `数` `字` `圈` | 单独的弦数 / 术语 / 圈 |
| `文1` `文2` … | 引号文字或小字注里的第 N 个字 |

| 写法 | 作用 |
|---|---|
| `弦~1.5,-2` | 部件偏移 (dx, dy) 像素 |
| `徽*0.9` | 部件缩放 |
| `弦=小42` | 指定所用变体（组件名） |
| `弦='四'` | 指定用字体字形 |
| `/40` | 上下分割：上部占 40% |
| `\|60` | 上部的左右分割：左手指占 60% |

例：`名十勾四 @388,28,44,68 | /38 弦=小42~0,1`

编辑器里拖动部件、缩放部件、按 `[` `]` 切换变体，都只会改写微调层。

## 结构式（逃生口）

`{…}` 内直接写字形结构，原子是组件名、引号字形或 `○`：

| 运算 | 含义 |
|---|---|
| `A / B` | A 在上、B 在下；`A /40 B` 指定上部占 40% |
| `A \| B` | A 在左、B 在右 |
| `A[B]` | B 放进 A 的内框 |
| `A + B` | 叠放在同一格 |
| `( )` | 分组 |

原子后可直接跟 `~dx,dy`、`*倍数`。结构式里的部件按出现顺序命名为 `#1`、`#2`…，结构式自带微调，不再使用 `|` 微调层。
